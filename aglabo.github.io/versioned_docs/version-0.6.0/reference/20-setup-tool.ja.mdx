> このアクションは **Linux ランナー専用** です (`ubuntu-latest`、`ubuntu-22.04` など) 。
> Windows・macOS はサポートしていません。

## リファレンス

このページでは、`setup-tool` アクションの入力パラメーター・動作・制約事項を説明します。
`setup-tool` は GitHub Releases からツールのアーカイブをダウンロードし、チェックサムを検証してからインストールします。

---

## アクション基本情報

ワークフローから以下のように参照します。

```yaml
- uses: aglabo/ci-platform/.github/actions/ca-setup-tool@v0.6.0
```

> 実際に使用する際には最新バージョンのタグを指定し、`gh actions-lock` でロックファイルを更新してください。

## 入力パラメーター

| パラメーター   | 型     | 必須   | デフォルト | 説明                                  |
| -------------- | ------ | ------ | ---------- | ------------------------------------- |
| `repo`         | string | はい   | —          | GitHub リポジトリ (`owner/repo` 形式) |
| `tool-version` | string | いいえ | `0.0.0`    | ツールバージョン (`X.Y.Z` 形式)       |

### `repo`

`owner/repo` 形式で指定します。GitHub Releases にアセットが公開されているリポジトリである必要があります。
リポジトリ名 (`/` より後ろ) がツール名、つまりインストールするバイナリ名になります。

```yaml
with:
  repo: rhysd/actionlint
```

補足:

- `owner` は英字で始まる英数字とハイフン (最大 39 文字) 、`repo` は英数字と `_`・`.`・`-` (最大 100 文字) のみ有効です。
  それ以外の値はエラーになります。

### `tool-version`

インストールするバージョンを指定します。`v1.7.12`・`1.7.12`・`1.7` のいずれの形式でも指定できます。

| 指定値    | 正規化後 | 取得するリリースタグ |
| --------- | -------- | -------------------- |
| `1.7.12`  | `1.7.12` | `v1.7.12`            |
| `v1.7.12` | `1.7.12` | `v1.7.12`            |
| `1.7`     | `1.7.0`  | `v1.7.0`             |

```yaml
with:
  repo: rhysd/actionlint
  tool-version: "1.7.12"
```

補足:

- 先頭の `v` / `V` は取り除かれ、`X.Y` 形式は `X.Y.0` に補完されます。
- `-beta` などのサフィックスは指定できません。
- 省略した場合はタグ `v0.0.0` を探します。最新リリースを自動で選ぶ機能はないため、**必ずバージョンを指定してください**。

## 動作

1. `repo` と `tool-version` を検証し、バージョンを正規化します。
2. `RUNNER_ARCH` からアーキテクチャ候補を決めます。
3. GitHub API (`/repos/<owner>/<repo>/releases/tags/v<version>`) からリリースアセットの一覧を取得します。
4. `*_linux_<arch>.tar.gz` と一致するアセットを、アーキテクチャ候補の順で探します。
5. アセットとチェックサムファイルをダウンロードし、SHA-256 を照合します。
6. アーカイブを展開し、ツール名と同じ名前のバイナリをインストールディレクトリに配置して `PATH` に追加します。

### アーキテクチャ候補

| `RUNNER_ARCH` | 探すアセット名の末尾 (優先順)               |
| ------------- | ------------------------------------------- |
| `X64`         | `_linux_amd64.tar.gz` → `_linux_x64.tar.gz` |
| `ARM64`       | `_linux_arm64.tar.gz`                       |

### チェックサムファイル

リリースアセットから次の順でチェックサムファイルを探します。

1. `checksums.txt`
2. 名前が `_checksums.txt` で終わるファイル

チェックサムファイルには `<tool>_<version>_linux_<arch>.tar.gz` のエントリーが必要です。

---

## 制約事項

| 制約           | 内容                                                                                    |
| -------------- | --------------------------------------------------------------------------------------- |
| OS             | Linux ランナー専用 (`ubuntu-latest` など)                                               |
| アーキテクチャ | `RUNNER_ARCH` が `X64` または `ARM64` のランナーのみ対応                                |
| リリースタグ   | `v<X.Y.Z>` 形式のタグでリリースされている必要がある                                     |
| アセット形式   | `<tool>_<version>_linux_<arch>.tar.gz` 形式の `.tar.gz` アセットのみ (`.zip` は非対応)  |
| チェックサム   | `checksums.txt` または `*_checksums.txt` がない、またはハッシュが一致しない場合はエラー |
| バイナリ配置   | アーカイブ直下にツール名と同じ名前のバイナリが必要                                      |
