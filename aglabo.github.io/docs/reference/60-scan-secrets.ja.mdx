> このワークフローは **Linux ランナー専用** です (ジョブは `ubuntu-slim` で実行されます) 。
> Windows・macOS はサポートしていません。

## リファレンス

このページでは、`ru-scan-secrets` ワークフローの入力パラメーター・動作・制約事項を説明します。
`ru-scan-secrets` は betterleaks と secretlint で呼び出し元リポジトリを走査し、機密情報の混入を検出します。
betterleaks は Git 履歴を、secretlint は checkout したファイルを走査します。

---

## ワークフロー基本情報

`jobs:` から以下のように参照します。

```yaml
jobs:
  scan-secrets:
    permissions:
      contents: read
    uses: aglabo/ci-platform/.github/workflows/ru-scan-secrets.yml@v0.9.0
```

> 実際に使用する際には最新バージョンのタグを指定し、`gh actions-lock` でロックファイルを更新してください。

## 入力パラメーター

| パラメーター         | 型     | 必須   | デフォルト              | 説明                                            |
| -------------------- | ------ | ------ | ----------------------- | ----------------------------------------------- |
| `version`            | string | いいえ | `1.10.0`                | インストールする betterleaks のバージョン       |
| `config-repo`        | string | いいえ | `aglabo/global-configs` | `global/configs` に checkout する設定リポジトリ |
| `config`             | string | いいえ | `""` (自動解決)         | betterleaks の設定ファイルのパス                |
| `fetch-depth`        | number | いいえ | `50`                    | 取得する Git 履歴の深さ (`0` で全履歴)          |
| `secretlint-version` | string | いいえ | `14.0.1`                | 実行する secretlint のバージョン                |
| `pnpm-version`       | string | いいえ | `""`                    | secretlint の実行に使う pnpm のバージョン       |

### `version`

インストールする betterleaks のバージョンを指定します。
betterleaks は [setup-tool](./20-setup-tool.ja.mdx) で `betterleaks/betterleaks` の GitHub Releases から取得します。

```yaml
with:
  version: "1.10.0"
```

### `config-repo`

betterleaks の設定ファイルを含むリポジトリを `owner/repo` 形式で指定します。
指定したリポジトリは `global/configs` に checkout されます。

```yaml
with:
  config-repo: my-org/my-configs
```

補足:

- checkout には `github.token` を使用します。プライベートリポジトリを指定する場合は、呼び出し元から読み取れる必要があります。

### `config`

betterleaks の設定ファイルのパスを指定します。
指定しない場合は、次の順に探して最初に見つかったファイルを使用します。

1. 呼び出し元リポジトリの `configs/betterleaks.toml`
2. `config-repo` のルートにある `betterleaks.toml` (`global/configs/betterleaks.toml`)

```yaml
with:
  config: ./.github/betterleaks.toml
```

補足:

- パスはリポジトリルートからの相対パスで指定します。
- `config` を指定してファイルが存在しない場合は、他の候補を探さず、エラーになります。
- `..` や空白を含むパス、ワークスペース外のパスは指定できません。
- `config-repo` 内の別の場所にあるファイルは、`./global/configs/<path>` の形式で指定します。

### `fetch-depth`

checkout する Git 履歴の深さを指定します。`0` を指定すると全履歴を取得し、betterleaks が全履歴を走査します。

```yaml
with:
  fetch-depth: 0
```

補足:

- 型は `number` です。文字列ではなく数値で指定します。

### `secretlint-version`

実行する secretlint のバージョンを指定します。

```yaml
with:
  secretlint-version: "14.0.1"
```

補足:

- `X.Y.Z` 形式で、メジャーバージョンは `14` 以上を指定します。`v` 接頭辞や `latest` などのタグは指定できません。

### `pnpm-version`

secretlint の実行に使う pnpm のバージョンを指定します。
空の場合は、呼び出し元リポジトリの `package.json` にある `packageManager` を使用します。

```yaml
with:
  pnpm-version: "10"
```

補足:

- `package.json` に `packageManager` がないリポジトリでは、`pnpm-version` を指定してください。

## 動作

2 つのジョブを並行して実行します。いずれかのジョブが失敗すると、ワークフローは失敗します。

### `scan-betterleaks`

1. 呼び出し元リポジトリを `fetch-depth` の深さで checkout します (`persist-credentials: false`)。
2. [validate-environment](./10-validate-environment.ja.mdx) でランナー環境を検証します (`actions-type: read`)。
3. 検証が成功した場合、[setup-tool](./20-setup-tool.ja.mdx) で betterleaks をインストールします。
4. `config-repo` を `global/configs` に checkout します。
5. 使用する設定ファイルを決定します。
6. `betterleaks git . --config <config>` で Git 履歴を走査します。結果は JSON 形式で `.github/report/betterleaks-report.json` に保存します。
7. 走査が失敗した場合 (終了コード `0` 以外) は、レポートを artifact `betterleaks-report` としてアップロードします (保持期間 30 日)。

### `scan-secretlint`

1. 呼び出し元リポジトリを `fetch-depth` の深さで checkout します (`persist-credentials: false`)。
2. pnpm をセットアップします。
3. `pnpm dlx secretlint@<secretlint-version>` でファイルを走査します。

secretlint は同梱の既定設定を使用します。設定ファイルを指定する入力はありません。

## 必要な権限

| 権限       | 値     | 用途                        |
| ---------- | ------ | --------------------------- |
| `contents` | `read` | リポジトリと設定の checkout |

## 制約事項

| 制約         | 内容                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------- |
| OS           | Linux ランナー専用 (`ubuntu-slim`)                                                                |
| タイムアウト | 各ジョブ 10 分                                                                                    |
| 設定ファイル | `config-repo` は `config` の値にかかわらず checkout される                                        |
| 走査範囲     | betterleaks は checkout した履歴のみ。既定 (`50`) では直近 50 コミットまで                        |
| レポート     | betterleaks の失敗時のみアップロードされる。検出箇所が含まれるため、artifact の公開範囲に注意する |
